# OSI 7 계층

## 물리 계층 physical
- 장치를 사용하기 위한 물리적인 사항을 정의
- bits
- 케이블, 안테나 같은 전송 매체, 허브, 리피터

- 허브
- physical layer 에서 다수의 기기를 연결해주는 장치
- 받은 내용을 그대로 전달. broadcast (모두)
- 확성기처럼 모두에게 전달. 특정 대상에게만 전달은 불가.
- 모두가 동시에 말하면 아무도 알아듣지 못함 -> 충돌
    - 조절하거나 막지 못함

## 데이터링크 계층 data link
- 물리적인 통신을 제어해서 디바이스간 통신 및 전송을 안정화 하기 위한 protocal
- frame
- mac address, switch
- 대상을 구별해 통신 지원. unicast(지정) 가능

* mac (media access control)
- network interface에 부여된 고유 주소, 대상 식별에 사용
- 고유 값으로 변동 x.
- 2개의 hex . 6개 나열. ex. 00:1A:3B:3C:4D:5E
    - 처음 3개 -> 제조사별 고유번호
    - 나머지: network interface 별 고유 번호

* csma/cd 충돌 해결
- carrier-sense mutliple access with colison detection
- jam signal 보내서 서로 인지
- random 시간 대기 후 다시 전송
- data link 의 한계
    - 로컬 네트워크에서 외부로 통신이 불가능
